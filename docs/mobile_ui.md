# Мобильный интерфейс

На экранах шириной до 900 px приложение занимает доступную высоту окна. Шапка
содержит историю, название, документы и новый диалог. Лента сообщений прокручивается
самостоятельно, поле ввода остаётся снизу и растёт до 128 px. История открывается
слева, документы — поверх чата; обе панели используют native dialog с удержанием
фокуса, Escape и возвратом к исходной кнопке. Создание подборки открывает второе
модальное окно поверх каталога. При переходе к настольной ширине панели возвращаются
в свои исходные места без копирования содержимого и обработчиков.

Ранее на 390×844 история, чат и документы складывались в страницу высотой 1715 px,
а поле ввода начиналось ниже 803 px. Теперь рабочая область ограничена экраном.
`visualViewport` учитывает изменение доступной высоты при появлении клавиатуры;
CSS использует `dvh` и safe-area. Масштабирование страницы не запрещено. Для
короткого экрана окно выбора документов допускает полную прокрутку формы.

На мобильном экране ответ не открывает первый источник автоматически: документ
появляется по нажатию на ссылку или карточку. Завершение ответа и загрузка истории
не переводят фокус в поле ввода, чтобы не вызывать клавиатуру без действия пользователя.

Реализация: `web/static/mobile.css`, `web/static/mobile-layout.js`; точки открытия
источника и выбора чата — в `web/static/app.js`. Списки и сохранение подборок общие
с настольным интерфейсом, см. [вкладки документов](document_tabs.md).

## Проверка

Штатный frontend-набор: `node --test web/tests/archive-scene.test.cjs`.
Отдельный сценарий Chromium требует установленного Playwright и запущенного веб-сервиса:

```sh
BASE_URL=http://127.0.0.1:8000 node web/browser-tests/mobile.cjs
```

При установке Playwright вне проекта задайте `NODE_PATH` к его `node_modules`;
для своего Chromium — `CHROMIUM_PATH`. Для защищённого стенда можно передать
`TEST_CREDENTIALS` — путь к приватному JSON с `username` и `password`.
Секреты не печатаются. Все операции чатов/подборок и ответ модели заменены фикстурами;
корпус читается из сервиса. Скриншоты сохраняются в `/tmp/legal-rag-*.png`.

Сценарий проверяет 390×844, 320×568, 390×420, 844×390, 768×1024, возврат к 1440×1000,
границы поля ввода, историю, Escape и восстановление фокуса, источник и возврат,
«Все», комбинированные фильтры и сохранение выбора скрытых документов.
Уменьшенная высота — имитация места, оставшегося от клавиатуры; это не проверка
реальной iOS/Android клавиатуры на физическом устройстве.


## Подтверждения внутри сайта

Перемещение диалога в корзину, окончательное удаление, удаление папок и
вкладок используют общее оформленное окно сайта с названием действия,
пояснением, «Отмена» и отдельной кнопкой подтверждения. Системный `window.confirm`
не используется. При открытии фокус на отмене; Escape отменяет только верхнее
подтверждение, оставляя окно редактирования или мобильную историю открытыми.
Кнопки доступны с клавиатуры, текст названий вставляется как текст.
Проверки: frontend-набор и браузерные сценарии `trash.cjs`, `folders.cjs`,
`mobile.cjs` проверяют принятие, отмену, Escape и отсутствие системных диалогов.
