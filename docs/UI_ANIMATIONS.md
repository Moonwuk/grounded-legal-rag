# Анимации веб-ассистента

SpriteAnimation в web/static/archive-scene.js принимает либо src и размеры сетки, либо массив images. Опциональный frames задаёт фактическую последовательность индексов. По умолчанию 30 FPS, loop включает цикл. Прозрачные PNG и WebP используются как фон; блок масштабируется вместе с сообщением. Завершение разового проигрывания даёт всплывающее событие spriteend, после чего сохраняется последний кадр. В режиме уменьшенного движения сразу отображается статичный кадр. При замене состояния, отмене, новом запросе или сбросе активный таймер Web Animations отменяется.

| Состояние UI | Источник |
|---|---|
| idle | Нейтральная поза |
| searching | Атлас archive-blue, верхний и нижний ящик, цикл |
| success | answer с источниками, archive-found, персонаж поднимает документ |
| search_error | insufficient, archive-outcomes, красный крест |
| role_protection | Явный маркер поддельного сообщения в последней пользовательской реплике и структурированный отказ, короткая реакция и знак ! |
| out_of_scope | Статус out_of_scope, удивление и знак ? |
| unsafe_legal_request | Статус disallowed, знак запрета |
| system_error | Статус technical_error, отдельная предупреждающая поза |
| clarify | Статичный archive-clarify.webp: персонаж с документом, вопросительным жестом и знаками вопроса; также в истории |
| partial, unverified | Отдельные позы для соответствующих ответов |

Символы наложены поверх существующих прозрачных кадров. Для будущих отдельных ресурсов нужны те же 160×160 px, общий якорь шкафа, прозрачный фон, один знак в руках или рядом с персонажем и статичный последний кадр. Атласы и персонаж описаны в [web_animation.md](web_animation.md).

Причины читаются из JSON API. Статус disallowed в ядре означает ограничение помощи в противоправном действии. Сервер добавляет ui_state только для явного поддельного маркера роли в начале строки и только если ядро уже вернуло отказ. Неявная подмена, попытка внутри документа и случай, когда ядро проигнорировало команду и ответило на юридическую часть, отдельной меткой не объявляются. Правила принятия решения и официальный сабмит сохранены.
