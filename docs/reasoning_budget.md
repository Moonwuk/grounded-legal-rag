# Уровень рассуждений модели и лимит токенов

11 ноября 2026. Модуль: `prototype/psb_llm.py` (`ProxyClient.complete`). Регрессии:
[tests/test_reasoning_budget.py](../tests/test_reasoning_budget.py).

## Симптом

Матрица на 18 демо-вопросах (`deepseek-flash`, публичный API, два потока)
дала технические ошибки `truncated_model_output` при малом `MAX_TOKENS`:

| `MAX_TOKENS` | уровень по умолчанию | `low` |
|---:|---|---|
| 1024 | 6 технических ошибок | 2 технические ошибки |
| 2048 | 1 техническая ошибка | без ошибок |
| 4096, 8192 | без ошибок | без ошибок |

`MAX_TOKENS` задаёт конфигурация задачи платформы; его значение заранее неизвестно.

## Первопричина

В каждом обрезанном ответе `reasoning_tokens` был равен `max_tokens` или
близок к нему (например, 1024 из 1024), обычно на этапе проверки. Видимого
ответа модель не успевала начать. Повтор после обрезки только просил
«минимальный JSON», что не сокращает скрытые рассуждения, поэтому второй
ответ обрезался так же.

## Исправление

- Повтор после обрезки, когда рассуждения заняли не меньше 80% лимита,
  отправляется на уровне `low`, если до этого был не заданный, `high` или `max`.
  На `low` повтор остаётся на `low` с просьбой о компактном JSON. Ниже `low`
  уровень автоматически не опускается (см. «Проверка на модели»).
  Если провайдер не сообщает `reasoning_tokens`, признаком служит видимый текст
  короче половины лимита в символах (каждый токен — не меньше одного символа).
  Длинный обрезанный видимый ответ уровень не меняет.
- По умолчанию передаётся `low`: на демо и на 100 вопросах синтетического
  holdout он не снизил точность и сократил время примерно на 41%
  ([отчёт](../evaluation/reports/STABILITY_AND_FULL_HOLDOUT.md), раздел 4).
  `LLM_REASONING_EFFORT=default` не передаёт параметр.
- Если запрос с параметром отвергнут с HTTP 400 или 422, он повторяется без
  параметра внутри тех же трёх транспортных попыток; если этот повтор успешен, до конца запуска параметр
  больше не передаётся. Ошибка другой природы повторяется и сообщается как `http_400`.
- Повторная обрезка по-прежнему технический сбой; частичный JSON не разбирается.

## Границы

- Принимает ли прокси организаторов `reasoning_effort`, не проверено; для этого
  и нужен повтор без параметра.
- При `MAX_TOKENS` около 1024 обрезка на уровне `low` остаётся возможной и даёт
  технический сбой; уровень платформы неизвестен.

## Проверка на модели

Демо, 18 вопросов, два потока; отчёты `matrix-5502269-*`. Код `5502269`
понижал и `low` → `none`.

| `MAX_TOKENS` | уровень | верно | технические сбои | `unverified` |
|---:|---|---:|---:|---:|
| 1024 | по умолчанию (`low`) | 17/18 | 0 (было 2) | 1 |
| 1024 | `high` | 13/18 | 5 (было 6 при уровне модели по умолчанию) | 0 |
| 2048 | по умолчанию (`low`) | 17/18 | 0 | 1 |

- `high` → `low` спас 6 из 11 обрезанных ответов; в остальных `low` тоже занял
  весь лимит 1024.
- Оба `unverified` — вопрос 5: проверка на `low` обрезалась, повтор на `none`
  отклонил верное положение, сокращение и повторная проверка закончились
  отказом. На `5dfe262` (без перехода на `none`) этот вопрос проходил. Поэтому
  переход на `none` убран; регрессия `test_default_low_is_not_lowered_to_none`.

## Лимит платформы MAX_TOKENS=1024 (после архива 24)

Платформа передаёт `MAX_TOKENS=1024` и `TEMPERATURE=0` (так записано в README сильнейшего
публичного решения; регламент, раздел 6: параметры «доступны скрипту для чтения»). Наши
локальные прогоны шли с 8192 и этого режима не проверяли. Прогон 14 ноября с 1024 на пяти
наборах (106 вопросов): у архива 24 — 20 обрезанных ответов, 6 `truncated_model_output`,
5 технических заглушек; у архива 12 — 26 обрезок и 10 заглушек. Рассуждения входят в лимит,
а обрезанный JSON разобрать нельзя.

Теперь нижняя граница лимита — 2048 (`MIN_OUTPUT_TOKENS`), бо́льшая настройка сохраняется;
повтор после обрезки, кроме понижения уровня рассуждений, получает удвоенный лимит до 4096
(`MAX_RETRY_TOKENS`). Тот же прогон с 1024: 3 обрезки, все исправлены повтором, 0 заглушек,
0 голых цитат, время то же. Регрессии — `PlatformBudgetTests` в
[tests/test_reasoning_budget.py](../tests/test_reasoning_budget.py). Модель платформы
локально недоступна: её длина рассуждений может отличаться.
