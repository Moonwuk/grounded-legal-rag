# Анимация поиска в веб-чате

Компонент: [archive-scene.js](../web/static/archive-scene.js), [стили](../web/static/archive-scene.css).
Двенадцать исходных поз пользователя перекрашены в синий и упакованы в `archive-blue.webp` (4×3).
Для ошибок и отказов подготовлены четыре отдельные позы в `archive-outcomes.webp` (2×2).
Растровые листы редактировались генеративным инструментом по исходным кадрам; это не побайтовая перекраска.

| Состояние API | Изображение |
|---|---|
| Запрос выполняется | Человечек открывает ящики и ищет; цикл без победных кадров |
| `answer` с источниками | Находит документ и поднимает его; финальный кадр остаётся |
| `partial` | Держит документ без победного жеста |
| `clarify` | Заглядывает в ящик; сохраняется текст уточнения |
| `technical_error`, сеть, таймаут | Достаёт и показывает жёлтый «!», жёлтая обводка только на последнем кадре |
| `insufficient`, `out_of_scope`, `disallowed`, `unverified` | Достаёт и показывает красный «×», красная обводка только на последнем кадре |
| Другой статус / `answer` без источников | Нейтральная поза |

Знаки — предметы в руках персонажа; на фасадах ящиков остаются обычные ручки. Цвет и поза дополняют текстовый статус, а не заменяют его.
Наличие цитат само по себе не включает победу: при отказе и технической ошибке остаётся соответствующая сцена.
Ответ отображается сразу; завершение анимации его не задерживает.
При `prefers-reduced-motion: reduce` показываются статичные кадры.
Сцена декоративная (`aria-hidden`); ежесекундный счётчик не создаёт повторных объявлений.
Отмена удаляет сообщение и его анимацию, повтор запускает новый поиск, сброс удаляет все сцены.
Компонент не вызывает API модели и не меняет политику ответа.

Проверка статусов и жизненного цикла запроса без модели:

```bash
node --test web/tests/archive-scene.test.cjs
```

Для проверки в браузере: выполнить запрос, увидеть поиск; проверить ответ с источником,
частичный ответ, уточнение, отказ, сетевую ошибку, повтор, отмену и новый диалог.
Проверить ширину 390 px и системное уменьшение движения.
