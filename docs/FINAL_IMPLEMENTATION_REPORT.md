# Отчёт о реализации

Ветка feature/psb-ui-deployment, [черновик PR №20](https://github.com/Moonwuk/grounded-legal-rag/pull/20). Основа — веб-ветка из PR №19 и main 1304005. Ядро, пакетный контракт, исходный ZIP и материалы массового прогона сохранены. Платный массовый прогон в рамках этой задачи не запускался.

## Реализовано

- web/app.py сохраняет HTTP-контракт text/status/sources, добавляет необязательный ui_state для явного поддельного маркера роли при структурированном отказе и отключает служебную документацию FastAPI.
- web/static сохраняет чат, SL UI и просмотр цитат. SpriteAnimation поддерживает атласы, отдельные PNG/WebP, 30 FPS, цикл, окончание, статичные кадры и отмену. Для защиты роли, непрофильного вопроса и правового ограничения используются отдельные значки на существующих кадрах.
- deployment содержит start, stop, status, restart, healthcheck, update и install-task. Агент проверяет официальный main, PR, одобрение финального SHA и GitHub Actions. Отдельная сборка, журнал, проверка и восстановление старого образа защищают рабочую копию.
- compose.yaml включает именованный образ и политику перезапуска. .github/workflows/web-ci.yml проверяет веб-сборку, frontend, HTTP, PowerShell и конфигурацию на GitHub-hosted runner.
- Инструкции находятся в [PROJECT_AUDIT.md](PROJECT_AUDIT.md), [UI_ANIMATIONS.md](UI_ANIMATIONS.md), [LOCAL_HOSTING.md](LOCAL_HOSTING.md), [CI_CD.md](CI_CD.md), [deployment.md](deployment.md) и [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md). Существующий регистр имени deployment.md сохранён для совместимости ссылок и Windows.

## Действия владельцев

Владельцу GitHub нужно согласовать порядок PR №19 и №20, настроить правила защиты main из CI_CD.md и обеспечить независимое одобрение последней версии. На ноутбуке уже работает локальная копия на 8000. Задача периодически проверяет main, а управляемая копия появится на 8001 после выполнения условий. Для внешнего адреса требуется домен в Cloudflare и список участников Access. До подключения нужно подтвердить права на показ выбранных документов и проверить HTTPS с другой сети.

Для запуска из рабочей копии используйте docker compose up --build -d --wait. Проверьте Invoke-RestMethod http://127.0.0.1:8000/healthz. После первой одобренной выкладки управляемая копия открывается по http://127.0.0.1:8001/, управление выполняется скриптами в deployment, журнал находится в %LOCALAPPDATA%\PsbLegalWeb\deployment.log.
