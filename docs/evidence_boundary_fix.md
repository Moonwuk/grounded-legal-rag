# Граница выдачи исходных положений и контроль отсутствующих ссылок

10 ноября 2026. Начальная база: main `64e65ff1c853c73d8977d0260a7ddf9c9ef2942f`. Во время работы интегрирован новый main `ab3bd08bc00631532669abce1bd1cdefc0da06d2` с batch Docker/IaC. Runtime последнего реального прогона: `e8560fa8c8b1f99f0ccfa45f74bde299a148ca4d`.

## Причины и исправления

1. **Потеря отрицания и условия.** Старый `source_wording` разрешал модельный тезис, являющийся подстрокой цитаты. «Вправе» входит в «не вправе», а цитата могла начинаться после условия. Теперь модель выбирает ID; приложение публикует полный доверенный исходный блок. Ни claim.text, ни выбранная моделью подстрока не определяют текст публикации. Проверяющая модель получает именно эту каноническую версию и готовый ответ. Даже одобряющая заглушка не может разрешить обрезание внутри блока.
2. **Окно поиска принималось за полное положение.** Длинный абзац мог разделить условие и норму. Окна восстанавливаются до исходных блоков по пустым строкам/структурным заголовкам; исходные координаты и hash сохраняются. Карантин — жёсткая граница: восстановление не возвращает удалённые инструкции. Ограничения контекста и ответа сохранены; превышение не исправляется обрезанием условия.
3. **Неполнота отсылочных оснований оставалась на модели.** Каталог статей строится по заголовкам и идентичности нормативного документа. Распознанная явная ссылка на отсутствующие статьи того же закона/кодекса переводит выбранный ответ в partial. Номера и сообщение формирует приложение по корпусу. Статья другого закона с тем же номером не закрывает пробел. Неизвестные формы не интерпретируются как доказанное отсутствие.
4. **Обрезка генерации.** Модель одновременно выбирала основания, сочиняла тезисы и копировала цитаты. Предпочтительный wire-формат теперь компактный `source_ids`; старый принимается без права управлять формулировкой публикации. При finish=length частичный JSON не разбирается и не выдаётся; разрешена одна свежая компактная попытка внутри прежнего бюджета трёх транспортных попыток и общего deadline. Повторная обрезка остаётся явной ошибкой.
5. **Недостаточная диагностика.** Безопасные события связывают этап, попытку, позицию вопроса, finish, числовой расход токенов и тип транспортного сбоя. Логи не содержат тела API, ключи или скрытые рассуждения. Сохраняются конечные пользовательские ответы для проверки.

Из доверенной конфигурации MAX_TOKENS учитывается до собственного предела 65536 вместо принудительного 8192; default остаётся 8192. Порядок для LLM_REASONING_EFFORT позже изменён: см. [reasoning_budget.md](reasoning_budget.md).

Генератор также различает заданные пользователем условия гипотетического сценария и реквизиты документа. Это смысловое поведение требует проверки, а не считается гарантией от наличия инструкции.

## Воспроизведение и автоматические проверки

На прежних runtime-модулях три целевые регрессии: **3 FAIL, 0 ERROR**. Они проверяют отрицание/условие, одобряющую заглушку и перенос отрицания на другую строку. Первоначальная расширенная проба с ещё отсутствующими интерфейсами сохранена отдельно и не выдаётся за три успешных воспроизведения.

После исправлений: 123 штатных теста; после интеграции batch Docker/IaC — **156 PASS**. Отдельная HTTPS-проверка контейнерного harness: **5 PASS**. Проверен фактически собранный ZIP: шесть корневых файлов, совпадение с runtime, CSV, дедлайн, локальный HTTP stub; зависимости — только stdlib.

При интеграции CI 42805000109 выявил несовместимость новой fixture: она требовала сокращённую цитату без номера пункта. Сбой воспроизведён локально. Fixture теперь строго требует полный исходный блок и отдельно отвергает его обрезанную версию; проверки CSV, TLS, bearer-auth и CWD import isolation сохранены.

Локально также прошли 8 тестов batch-runner. Ansible guard tests требуют ansible-core 2.22/Python 3.13: в локальном Python 3.12 пакет отсутствует; запуск и ограничение записаны отдельно. Полная IaC-проверка выполняется в CI.

Поиск: **32/32 положительных сценария разработки**; это не независимая оценка. Новые регрессии используют другие числа, даты, имена и законы. Тесты/эталоны не входят в runtime.

## Оставшиеся границы

Полный исходный блок не доказывает применимость, правильную редакцию, полноту ответа или отсутствие ограничений в другом блоке. Смысловая оценка остаётся модельной. Выдача выдержек пока менее удобна, чем проверенный явный вывод; улучшать её следует без возврата обхода через подстроку.

Каталог распознаёт ограниченные формы ссылок; модель может выбрать нерелевантные ID или дать ложный отказ. Ограниченный retry не гарантирует получение ответа при любом сбое.

**Безусловная готовность к следующему сабмиту не подтверждена:** остаются самодостаточность/краткость и непроверенный API организаторов. Механические проверки, смысловой разбор, совместимость платформы и официальный Score разделены. Результат 17 PASS — внутренняя ручная оценка, не прогноз балла.

Новый main содержит batch Docker/IaC. Финальные веб-чат с просмотром источников и PDF-презентация этим PR не реализованы; batch-контейнер не подтверждает готовность финального продукта.
