# Граница выдачи исходных положений и контроль отсутствующих ссылок

База: main 64e65ff1c853c73d8977d0260a7ddf9c9ef2942f, 10 ноября 2026.

## Подтверждённые причины

1. `source_wording` разрешал модельный тезис, если тот был подстрокой цитаты. «Вправе» является подстрокой «не вправе». Кроме того, сама цитата могла начинаться после условия. Это два независимых места потери смысла. Положительный LLM-verdict не исправляет ни одно из них.
2. Поисковые окна длинного абзаца использовались как готовые единицы выдачи. Начало условия могло остаться в другом окне. Переносы строк требуют восстановления исходного блока; карантинные инструкции нельзя возвращать при таком восстановлении.
3. Общая инструкция модели не обеспечивала раскрытие отсутствующих отсылочных норм. Необходим отдельный каталог исходных документов и типизированное сообщение о границе доступных сведений.
4. `length` немедленно превращался в технический ответ. Генератор одновременно должен был выбирать основания, писать тезисы и копировать цитаты, хотя приложение умеет восстановить их по ID. Собственный жёсткий предел 8192 также обрезал явно заданный больший MAX_TOKENS.

## Изменения

- Модель может возвращать компактный `source_ids`. Текст публикации и цитат приложение берёт только из доверенных объектов evidence. Поле claim.text и выбранная моделью подстрока не определяют публикуемую формулировку. Неизвестные/повторные ID, конфликтующие схемы и поддельные цитаты проверяются кодом. Старый wire-формат принимается для совместимости, но также не получает права определять текст выдачи.
- Перед выдачей поисковые окна восстанавливаются до полных исходных блоков по пустым строкам/структурным заголовкам. Исходные координаты и hash участвуют в ID. Карантин — жёсткая граница восстановления. Ограничения 100000 символов/512 блоков и 10000 символов ответа сохраняются; недопустимый объём не обрезается с потерей условий.
- Каталог статей строится из заголовков корпуса и идентичности нормативного документа. Явные ссылки вида «части ... статьи ... настоящего Федерального закона/Кодекса» сопоставляются с каталогом. При недостающем положении ответ становится partial, а сообщение о недостающих статьях формируется приложением. Пробел считается по полному каталогу, а не по пустому top-k; бесполезное расширение поиска для уже установленного отсутствия не выполняется.
- Генератор получает правило о различии фактов условного сценария пользователя и реквизитов найденного договора. Это смысловое поведение по-прежнему требует проверки; наличие текста инструкции не объявляется доказательством его соблюдения.
- При `length` запрещены разбор и публикация частичного JSON. Допускается ровно одна свежая компактная попытка в общем лимите трёх транспортных попыток и общего deadline. Повторная обрезка остаётся явной технической ошибкой. Лимит логических вызовов не увеличен.
- MAX_TOKENS из доверенной конфигурации учитывается до собственного предела 65536 вместо прежнего 8192; без конфигурации остаётся 8192. Необязательный LLM_REASONING_EFFORT принимается только из фиксированного списка и не задаётся автоматически. Совместимость этого параметра с организаторским прокси не утверждается.
- Метаданные API сохраняют этап, номер попытки, finish и числовой расход токенов, если он предоставлен. Ключи, тело ответа провайдера и скрытые рассуждения не сохраняются.

## Проверка

Три отрицательные проверки на прежних runtime-модулях завершились 3 FAIL, 0 ERROR. Они проверяют сохранение отрицания/условия, публикацию при одобряющей заглушке и перенос отрицания на другую строку. Их результаты сохранены отдельно от успешного прогона новой реализации.

Штатный набор: 122 PASS. Поиск: 32/32 положительных сценария разработки, не независимая оценка качества. Архив пересобран и проверен штатными submission/dependency gates. Новые случаи дополнительно проверяют восстановление длинного абзаца, отсутствие/наличие статьи в том же законе, другой закон с тем же номером статьи, короткий wire-формат, отказ от публикации обрезки, восстановление после обрезки и учёт заданного token cap.

Реальные 18 demo и отдельные 8 синтетических сценариев записываются в новый каталог results/evidence_boundary_*. Синтетические эталоны определены до первого живого запуска и не передаются в runtime. Это ограниченный свежий набор, а не независимый внешний benchmark. После его использования для настройки он перестанет быть контрольным.

## Границы

Полный исходный блок не доказывает применимость, правильную редакцию, полноту ответа или отсутствие ограничений в другом блоке/документе. Этот PR закрывает воспроизведённые способы обрезки внутри публикуемого блока; он не заявляет формальную проверку произвольного юридического смысла. Каталог распознаёт ограниченные явные формы ссылок и заголовков; неизвестные формы не интерпретируются как доказанное отсутствие статьи.

Повтор `length` — ограниченное восстановление, а не гарантия получения ответа при любом лимите/сбое. Отключение thinking не включается автоматически: предыдущий эксперимент был быстрее, но дал ложное уточнение. Фактические настройки API организаторов и прирост конкурсного Score требуют отдельной проверки.

Финальный веб-интерфейс, Docker-комплект и административная защита main находятся вне этих исправлений. Отсутствующие обязательные компоненты не объявляются готовыми.
