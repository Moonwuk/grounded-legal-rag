  текстов рассуждений провайдера. После опыта процесс завершён.

Это прямой API DeepSeek, не конкурсный прокси. Время на известном небольшом
наборе с высоким попаданием в кэш не гарантирует время на скрытом наборе.
Загрузка на конкурсную платформу не выполнялась.

## Отделение эффекта фильтра от различий генерации

Сохранённые ответы двух живых прогонов не идентичны даже при температуре 0.
Поэтому дополнительно 38 содержательных кандидатов с выбранными источниками
проверены **обоими** `scope_block_reason` без новых API-вызовов. Текст каждого
источника сопоставлен точному диапазону документа корпуса.

Новых отказов нет. Старый фильтр отвергает два кандидата Q17, полученных в
исправленном прогоне, как `added_assertion`; новый принимает оба. Это два
вызова для одного вопроса, а не два независимых тестовых вопроса. В них
используется «он определяется производителем», что демонстрирует эффект
исправления на реальной генерации. Это проверка фильтра, не повтор всего
пакетного алгоритма на фиксированных ответах.

В Q16 обе модели выбрали допустимые для обоих фильтров формулировки: улучшение
именно этого вопроса в живом сравнении не измерено. Его официальный полный
текст проверен отдельно в детерминированной регрессии.

Q9 в исправленном прогоне содержит связный ответ вместо цитат. Приписывать
это исправлению нельзя: тексты генерации различаются, а прежний отказ был
по `exclusive_word`, вне изменённого механизма.

## Проверка полноты

Сопоставление всех ответов с эталонами ассистентом не обнаружило явной подмены
сумм, сроков, контрагентов или редакций. Это не независимое экспертное заключение.
Есть отличия по полноте, которые автоматические 18/18 не отражают:

- Q1: обе сборки не добавили сведения об отдельной оплате коммунальных услуг
  и электричества из эталона; на прямо заданные сумму и срок ответили.
- Q4: исправленная сборка не повторила «включая НДС»; сумма, предел повышения,
  уведомление и отсутствие документа о повышении сохранены.
- Q6: обе сборки не добавили срок приёмки по количеству; срок по качеству и
  событие отсчёта (подписание УПД) сохранены. Пункт 3.3 приведён в тексте цитаты,
  но итоговая строка «Источник» перечисляет только пункт 6.1.
- Q13: обе сборки указали отсутствующие статьи и ограничение применимости,
  но не повторили рекомендацию обратиться к юристу.
- Q14: обе сборки сохранили условие природной сезонности, но не добавили
  отдельную последнюю фразу эталона о характере конкретной должности.
- Q17: ограничение вывода и необходимость гарантийного талона сохранены.

Перед единственной загрузкой новые изменения поиска, промпта или очереди
по этим наблюдениям не вносились. Конкурсный ZIP остался тем же, который
прошёл 474 теста ядра, 106 тестов оценочных адаптеров и GitHub CI.
