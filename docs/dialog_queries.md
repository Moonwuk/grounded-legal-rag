# Поиск по диалогу: нужно ли переписывать последнюю реплику

12 ноября 2026. Решение: **не переписывать**; поиск по-прежнему учитывает
прошлые реплики пользователя с весом 0,35 и идентификаторы и контрагентов из
истории (`Retriever.search`).

## Замер

`evaluation/make_dialogs.py` построил 26 диалогов из вопросов
`eval/cases.json`: последняя реплика без истории непонятна («А сколько по нему
платить и до какого числа вносить?»), по смыслу равна исходному вопросу,
эталонные положения те же (`evaluation/questions/dialogs.json`). Сравнение —
наличие всех эталонных положений в контексте:

| | Как сейчас | Самостоятельный вопрос, переписанный моделью |
|---|---:|---:|
| Обычный поиск | 25/26 | 24/26 |
| Расширенный поиск | 26/26 | 26/26 |

Переписывание не улучшило поиск и однажды ухудшило его: в запрос попало
название контрагента из истории («ООО «Ромашка»»), не связанное с нужным
положением. Лишний вызов модели на каждый диалоговый вопрос не оправдан.

## Границы

Диалоги и переписанные запросы написаны моделью решения на основе набора
настройки; это измерение разработки, не независимый контроль.
