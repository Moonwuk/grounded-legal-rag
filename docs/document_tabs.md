# Вкладки документов

Каталог разделён на «Законы», «Договоры», «Регламенты» и «Прочее». Законы определяются
по категории корпуса; договоры, допсоглашения и регламенты — по началу названия.
Остальные документы находятся в «Прочее». Каждый документ входит ровно в один
стандартный раздел. Поиск по названию работает внутри выбранной вкладки.

«+ Создать вкладку» открывает окно с названием и флажками документов существующей
базы. Можно создать пустую подборку, затем через «Изменить» переименовать её,
добавить или убрать документы. Удаление вкладки требует подтверждения и не удаляет
документы. Возврат из просмотра документа сохраняет выбранный раздел и поиск.
Стрелки влево/вправо, Home и End переключают вкладки с клавиатуры.

Свои вкладки хранятся в таблице `document_tabs` той же SQLite, что и
[история чатов](chat_history.md), и требуют той же настройки прокси и тома.
Под одним логином подборки доступны с разных устройств; после изменений на другом
устройстве нажмите «Обновить» или перезагрузите страницу. Чужие подборки недоступны.
Стандартные разделы работают и без серверного хранения.

API `/api/document-tabs`: GET — список, POST — создание;
`/api/document-tabs/{id}`: PUT — изменение, DELETE — удаление.
Тело POST/PUT: `title`, `document_ids`, при изменении — `revision`, полученная
при чтении. Устаревшая ревизия возвращает 409, чтобы не затереть изменения с другого
устройства. Лимиты: 30 подборок на логин, название 1–60 символов после обрезки
пробелов, до 500 ID и 64 КиБ запроса. ID проверяются по загруженному корпусу;
повторяющиеся ID удаляются. Все ответы приватные, без кеширования.

Подборки организуют просмотр документов. Они не ограничивают поиск ассистента:
ответы по-прежнему учитывают весь корпус. Загрузка файлов в этой функции не предусмотрена.
Если оператор заменяет корпус, исчезнувшие ID не показываются и убираются из
подборки при следующем сохранении в интерфейсе.

Проверки: `python -m unittest discover -s web/tests -v` проверяет хранение,
изоляцию, удаление без потери корпуса, конфликты ревизий, лимиты и валидацию.
`node --test web/tests/archive-scene.test.cjs` проверяет разбиение документов,
допсоглашения, свои подборки и поиск внутри вкладки. Ручной браузерный сценарий:
создание → выбор документов → просмотр и возврат → второе устройство → изменение
→ удаление; проверить также мобильную ширину и клавиатуру.
