W2 исправил добавленную исключительность во второй попытке; W3 сохранил отсылку и запросил сервисный паспорт; W4 ответил про изготовителя, не потребовав паспорт. W1 не дошёл до VERIFY; исходный журнал не содержит достаточно полей, чтобы точно восстановить, какая проверка схемы его отвергла.

Отдельная безопасная диагностика [W1](../results/warn_diagnostic_20261110T170237Z/W1.json) и [demo3](../results/warn_diagnostic_20261110T170237Z/demo3.json) не заменяет исходный прогон. Поэтому исправлен воспроизведённый дефект формы: для insufficient без issue пустой код превращается в собственный код document. Неизвестные/неверные коды не исправляются, одобрение отказа по-прежнему обязательно. В диагностике сохранены только разрешённые коды, статусы, количества, флаги и категории причин, без сырых тел API, секретов или скрытых рассуждений.

## Промежуточный полный прогон

[ZIP2ac10716](../results/warn_final_live_20261110T170616Z/submission_summary.json):18строк за259,886с,0technical/0unverified. Четыре прежних замечания при внутреннем чтении закрыты:3 — вопрос о пособии явно назван;10 — нет «лишь»/исключительного перечня;13 —141слово с полными цитатами;17 —partial и запрос гарантийного талона. [Ручная сверка](../results/warn_final_live_20261110T170616Z/manual_review.json).

При этом новый scope guard дважды отправил16в запасной формат:163слова с полным дополнительным соглашением, ненужным для включения упаковки и доставки в цену. Это сохранённое новое замечание к полезности/длине, не утверждение об ошибке числа. Общего retry_reason недостаточно для точного исправления: модель не знала, что приложение блокирует ограничительную формулировку. Добавлен программный retry_scope_guard и инструкция переформулировать положительно, убрать необязательные выводы, сохраняя существенные условия. Барьер не ослаблялся, число попыток не увеличивалось. [Регрессия до изменения](../results/warn_scope_retry_before.txt).

[Четыре синтетических сценария ZIP2ac10716](../results/warn_final_synthetic_20261110T170615Z/submission_summary.json):140,586с,0technical/0unverified, [внутренняя ручная сверка4PASS](../results/warn_final_synthetic_20261110T170615Z/manual_review.json).
