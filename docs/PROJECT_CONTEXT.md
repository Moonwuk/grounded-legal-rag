# Контекст для следующего сеанса

Moonwuk/grounded-legal-rag содержит конкурсный Python RAG и веб-обёртку FastAPI. Результат answer_structured имеет text/status/sources, а answer_question сохраняет пару для prototype/solution.py. Corpus и Retriever создаются при старте. UI на HTML/CSS/JS использует SL UI, локальную историю и точные ссылки на фрагменты. Таблица состояний в [UI_ANIMATIONS.md](UI_ANIMATIONS.md). Полный путь запроса и раздельные подсистемы описаны в [PROJECT_AUDIT.md](PROJECT_AUDIT.md).

Текущая задача развивается в feature/psb-ui-deployment, основана на web-chat и открыта как [черновик PR №20](https://github.com/Moonwuk/grounded-legal-rag/pull/20) в main. Локальная демо-копия на 8000, управляемая установка ожидает проверенный merge и использует 8001. Для разового запуска docker compose up --build -d --wait. API настраивается через LLM_BASE_URL, LLM_API_KEY, LLM_MODEL. Для production обновления см. [deployment.md](deployment.md). При проверках используйте Linux-контейнер для тестов ядра с Unix-специфичными API. Текущие результаты, известные границы и незавершённые действия вынесены в [FINAL_IMPLEMENTATION_REPORT.md](FINAL_IMPLEMENTATION_REPORT.md).

Ветка другого участника и артефакты большого DeepSeek-прогона независимы. Сохраняйте исходный конкурсный корпус в organizer и тестовые корпуса в evaluation. Внешний доступ требует авторизации владельца Cloudflare и отдельной проверки HTTPS.
