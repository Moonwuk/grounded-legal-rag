## Ограничения

Это ограниченные распознаватели русского текста, не универсальное доказательство смысла. Перечень ограничивающих операторов и отрицательных функций неполон. Совпадение ограничивающего слова в другом месте не доказывает применимость; смысл проверяет модель. Отсылка распознаётся для явной конструкции значения, а тема — по префиксам слов; другие конструкции могут быть пропущены. Совпадение заголовка только выключает дополнительное предупреждение: оно не подтверждает применимость документа. Отсутствие совпавшего заголовка не доказывает отсутствие норм во всём корпусе; поэтому текст запрашивает отсылочный документ и не заявляет глобальное отсутствие условия.

Рекомендация150слов не достигается обрезкой цитат или удалением условий. Цитируемый запрос ограничен240символами и отбрасывается при ссылках, разметке ролей, управляющих символах либо превышении длины. Предыдущие отказы/ошибки сохранены; результаты API организаторов и официальный Score не проверены.

Живой прогон окончательного ZIP: ожидается; прежние результаты ему не присваиваются.
