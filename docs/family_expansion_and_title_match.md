# Расширение по связанным документам и сопоставление названий

Два дефекта найдены на стенде оценки; проверки без вызовов модели —
[test_scaling_and_references.py](../tests/test_scaling_and_references.py).

## 1. Чужие семейства документов переполняли контекст

**Симптом.** `evidence_size_limit` (технический ответ) в 1–2 вопросах из 12 в
каждом реальном прогоне на синтетическом корпусе.

**Первопричина** (`psb_retrieval.py:Retriever.search`). Каждое лексическое
попадание подтягивало все документы с тем же номером договора, включая
попадания по другому договору: в плотном корпусе похожие формулировки дают
кандидатов из многих семейств. Обязательное сохранение связанных документов
обходит мягкий бюджет контекста, и итог превышал жёсткий предел 100 000
символов. Воспроизведено без модели на 500 синтетических вопросах.

**Исправление.** Если в вопросе назван идентификатор, связанные документы
подтягиваются только для попаданий с этим идентификатором. Попадание по
другому договору остаётся кандидатом само по себе. Без идентификатора в
вопросе поведение прежнее.

| 500 синтетических вопросов, TOP_K=6 | до | после |
|---|---:|---:|
| ошибки, обычный поиск | 0 | 0 |
| ошибки, расширенный поиск | 177 | 25 |
| достаточный контекст, обычный поиск | 394/394 | 394/394 |
| достаточный контекст, расширенный (где нет ошибки) | 247/247 | 394/394 |
| медиана контекста, обычный поиск, символов | 45 472 | 13 879 |

На базе организаторов `audit_retrieval.py` даёт идентичный результат до и
после (кроме времени): 32/32 случая, `span_recall` 1.0.

**Остаток.** 25 ошибок — один повторяющийся непрофильный вопрос без
идентификатора в расширенном поиске; до него доходит только повторная попытка.

## 2. Имеющийся документ считался отсутствующим

**Симптом.** Положение «…указывается в гарантийном талоне» при наличии файла
«Гарантийный талон …» давало `partial` с просьбой предоставить документ.

**Первопричина** (`psb_policy.py:value_dependencies`). Название сопоставлялось
по основам поисковых токенов, которые строятся только для слов от шести букв:
«талоне» давало основу, «талон» — нет.

**Исправление.** `_title_stems`: короткая основа каждого слова (три буквы для
слов из трёх-четырёх, иначе четыре). Затронуто только это сопоставление;
поисковые токены не менялись. Совпадение названия лишь снимает дополнительное
предупреждение и не доказывает применимость документа.
