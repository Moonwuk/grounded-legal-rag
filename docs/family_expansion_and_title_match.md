# Расширение по связанным документам и сопоставление названий

Два дефекта найдены на стенде оценки; проверки без вызовов модели —
[test_scaling_and_references.py](../tests/test_scaling_and_references.py).

## 1. Чужие семейства документов переполняли контекст

**Симптом.** `evidence_size_limit` (технический ответ) в 1–2 вопросах из 12 в
каждом реальном прогоне на синтетическом корпусе.

**Первопричина** (`psb_retrieval.py:Retriever.search`). Каждое лексическое
попадание подтягивало все документы с тем же номером договора, включая
попадания по другому договору: в плотном корпусе похожие формулировки дают
кандидатов из многих семейств. Обязательное сохранение связанных документов
обходит мягкий бюджет контекста, и итог превышал жёсткий предел 100 000
символов. Воспроизведено без модели на 500 синтетических вопросах.

**Исправление.** Если в вопросе назван идентификатор, связанные документы
подтягиваются только для попаданий с этим идентификатором. Попадание по
другому договору остаётся кандидатом само по себе. Без идентификатора в
вопросе поведение прежнее.

| 500 синтетических вопросов, TOP_K=6 | до | после |
|---|---:|---:|
| ошибки, обычный поиск | 0 | 0 |
| ошибки, расширенный поиск | 177 | 25 |
| достаточный контекст, обычный поиск | 394/394 | 394/394 |
| достаточный контекст, расширенный (где нет ошибки) | 247/247 | 394/394 |
| медиана контекста, обычный поиск, символов | 45 472 | 13 879 |

На базе организаторов `audit_retrieval.py` даёт идентичный результат до и
после (кроме времени): 32/32 случая, `span_recall` 1.0.

**Остаток и его причина.** 25 ошибок оставались на одном повторяющемся
непрофильном вопросе без идентификатора («напиши рецепт пирога…»). Бюджет
контекста считался по отдельным документам, а связанные документы
каждого принятого добавлялись после него — мимо бюджета. При слабых
разбросанных совпадениях это давало контекст больше предела (обычный поиск
этого вопроса — 84 тыс. символов при бюджете 42 тыс.).

**Исправление.** Бюджет считается по единице «документ вместе со всеми
связанными» (и с регламентами для регламента согласования): семейство
входит целиком или не входит вовсе, поэтому допсоглашение по-прежнему не
отделяется от договора, а бюджет больше не обходится. Порядок документов
на выходе прежний.

| 500 синтетических вопросов, итоговый код | обычный | расширенный |
|---|---:|---:|
| ошибки | 0 | 0 |
| достаточный контекст | 394/394 | 394/394 |
| максимум контекста, символов (бюджет) | 38 830 (42 000) | 60 636 (65 000) |

Аудит поиска на базе организаторов идентичен прежнему, кроме времени.
Отброшенное целиком семейство — это документы ниже по приоритету; явного
признака неполноты поиск пока не возвращает.

## 2. Имеющийся документ считался отсутствующим

**Симптом.** Положение «…указывается в гарантийном талоне» при наличии файла
«Гарантийный талон …» давало `partial` с просьбой предоставить документ.

**Первопричина** (`psb_policy.py:value_dependencies`). Название сопоставлялось
по основам поисковых токенов, которые строятся только для слов от шести букв:
«талоне» давало основу, «талон» — нет.

**Исправление.** `_title_stems`: короткая основа каждого слова (три буквы для
слов из трёх-четырёх, иначе четыре). Затронуто только это сопоставление;
поисковые токены не менялись. Совпадение названия лишь снимает дополнительное
предупреждение и не доказывает применимость документа.

## 3. Роли документов без опоры на имена файлов

**Симптом.** Семейство регламента собиралось, только если имя файла содержало
«регламент согласования», а законы исключались по префиксу `законы__`. На той
же базе с другими именами (`doc_01.txt` …) редакции регламента и ссылающееся
на него письмо переставали подтягиваться вместе.

**Исправление.** Закон — документ, у которого в заголовке распознан кодекс или
федеральный закон (`law_by_doc`, уже по тексту). Регламент — документ, одна из
первых трёх непустых строк которого начинается со слова «Регламент». Ключ —
первые слова заголовка до формы организации («регламент согласования
договоров»). Семейство — редакции с тем же ключом и документы, цитирующие это
название (письмо К-12: «Регламента согласования договоров»).

**Проверка.** На базе организаторов семейство то же, что прежде (две редакции и
письмо К-12), `audit_retrieval.py` идентичен прежнему. С непрозрачными именами
файлов найдены все 32/32 эталонных положения. На общем корпусе (1265
документов) ни один синтетический документ не стал регламентом, семейства не
расширились. Регрессии — [tests/test_naming_independence.py](../tests/test_naming_independence.py).
