# Компоненты SL UI Library

Версия пакета 1.2.4. Использованы варианты Vanilla. Разметка, SVG, стили и контроллеры взяты из экспорта. В проекте применены русские подписи и локальная палитра. Лицензии и шрифты лежат рядом с исходниками в static/vendor/sl-ui.

Отправка вызывает API чата через onSend. Индикатор завершения появляется после ответа сервера. Escape на кнопке отменяет ожидание в браузере. Copy записывает выделенный диапазон из открытого документа по явному нажатию.
