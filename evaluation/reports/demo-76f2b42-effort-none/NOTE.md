# Демо: уровень рассуждений модели

Код `main` 76f2b42, 18 демо-вопросов, `deepseek-flash`, публичный API DeepSeek.
`LLM_REASONING_EFFORT` передан решению через `run_corpus` (записан в summary).
По одному прогону; решение настраивалось на этих вопросах.

| Уровень | Время | Верно (элементы) | Ответы-цитаты | Медиана выходных / рассуждений токенов на вызов |
|---|---:|---:|---:|---:|
| по умолчанию (3 прогона, `demo-76f2b42-r1..r3`) | 116–150 с | 18/18 (по ручной сверке) | 1–3 | 610 / 487 |
| `low` (`demo-76f2b42-effort-low`) | 96 с | 18/18 | 2 | 478 / 380 |
| `none` (`demo-76f2b42-effort-none`) | 44 с | 16/18 — 2 общих отказа | 3 | 133 / 0 |

`none` втрое быстрее, но даёт ложные отказы (вопросы 3 и 5). `low` сохраняет
качество на демо; решение о смене значения по умолчанию требует замера на
holdout (100 вопросов).
