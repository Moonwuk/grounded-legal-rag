# Smoke на исправленном корпусе и с чтением связного текста

Те же 12 вопросов synthetic (корпус `synthetic-b148e60beaa44f30`), стенд на
коммите `0f98b40`, `deepseek-flash` через публичный API DeepSeek (не модель
платформы), настройки генерации runtime. 29 вызовов модели + 2 probe;
~577,8 тыс. входных и ~55,8 тыс. выходных токенов.

Чтение текста калибровалось на ответах к этим же вопросам из прогона
`f39195a`. Ответы этого прогона новые, но вопросы те же: это проверка на
свежих формулировках, а не независимый контроль.

| Кейс | Решение | Валидатор при прогоне | Перепроверка (после исправления чтения) | Ручная сверка |
|---|---|---|---|---|
| contradiction-0001, fact-0000, fact-0001, security-0000, security-0001, temporal-0001 | answer | pass | pass | верно |
| missing_information-0001 | insufficient | pass | pass | верно |
| multi_document-0001 | answer | **fail** | pass | верно — ложное отклонение валидатора |
| multi_document-0000 | unverified | fail (false_refusal) | fail | ложный отказ решения |
| missing_information-0000 | unverified | fail | fail | общий отказ вместо уточнения даты |
| contradiction-0000, temporal-0000 | technical_error | system_error | system_error | `evidence_size_limit` в production-поиске |

`multi_document-0001`: чтение текста приняло «условие допсоглашения о 75 …
с 2026-07-02 … не наступило» за утверждение, а условия согласования искало
только рядом с выводом, хотя они стоят в предложении «Согласование: …».
Исправлено в `validators/prose.py` с регрессиями в `test_prose_reader.py`.

Два `unverified`: 4 вызова модели без принятого кандидата; в прогоне
`f39195a` те же вопросы прошли. Стенд этого прогона не сохранял вердикты
проверки, поэтому причина не установлена; с этого коммита worker пишет
типизированные `model_steps`.

`evidence_size_limit` повторяется: 1, 1 и 2 кейса из 12 в трёх прогонах на
плотном синтетическом корпусе. Это production-поведение; применимость к базе
организаторов (21 документ) не установлена.
