# Демо организаторов через solution.py

18 демо-вопросов, база организаторов, неизменённый `prototype/solution.py`
(код `main` 90c51e2), стенд `f744e96`, `deepseek-flash` через публичный API
DeepSeek (не модель платформы). 141 с на весь набор, 2 потока.
Решение настраивалось на этих вопросах: измерение не независимое.

Проверка по элементам: 17 pass, 1 not_evaluated, 0 fail, 0 отказов,
0 технических ошибок. Ручное чтение всех 18 ответов: ошибок по существу нет.

**Риск для LLM-судьи: 5 ответов — только цитаты без вывода** (2, 9, 13, 14, 17;
`prose: source_only` в журнале решения). Эталон организаторов отвечает прямо
(«Да…», «не может превышать шести месяцев»), решение публикует положения:

| Вопрос | Что опубликовано | Чего нет по сравнению с эталоном |
|---|---|---|
| 2 | цитата ч. 5 ст. 70 и редакционное примечание об изменении статьи | прямого «шесть месяцев»; примечание лишнее |
| 9 | п. 4.1 и 4.2 | вывода «предоплата допускается по соглашению сторон» |
| 13 | ч. 2 и 3 ст. 9, предупреждение об отсутствующих статьях | вывода о том, что удалять всё сразу не обязательно |
| 14 | две цитаты ст. 59 | «Да» и условия применения |
| 17 | п. 6.1 и просьба предоставить талон | фразы, что срок в договоре не установлен |

Причина в `psb_policy.py`: для положений с распознанным запретом или условным
разрешением (`_SOURCE_ONLY`) и при отсылке к другому документу (`value_gaps`)
текст модели намеренно не публикуется (AGENTS 4.9, docs/prose_safety.md).
Это проектное решение, а не сбой; как его оценивает судья, локально не измерено.

Ложные отказы из holdout (неприменимое контрастное положение отклоняет весь
ответ) на демо не проявились: во всех принятых проверках отклонённых положений нет.
