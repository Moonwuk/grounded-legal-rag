# Корпуса в формате платформы

Каждый корпус — каталог, который можно прогнать через неизменённый
`prototype/solution.py` тем же контрактом, что на платформе:

```text
<corpus>/
  corpus.json          # идентификатор, путь и SHA-256 базы и вопросов, пометка о настройке
  data/questions.csv   # id,question; история диалога внутри поля question
  gold/cases.json      # эталон по элементам; решению не передаётся
```

Запуск (ключ — только через окружение):

```bash
LLM_BASE_URL=... LLM_API_KEY=... LLM_MODEL=... python3 -m evaluation.run_corpus --corpus evaluation/corpora/demo --run-id my-demo
```

Решение получает временный `DATA_DIR` с `knowledge-base.zip` и `questions.csv`.
Ответы из `submission.csv` проверяет [validators/elements.py](../validators/elements.py):
допустимый статус, обязательные элементы (значение с единицей, номер пункта,
ключевая формулировка, «да/нет») и запрещённые утверждения. Это проверка
наличия ключевых элементов, а не полного юридического смысла и не Score.

Новый корпус добавляется каталогом; код менять не нужно. `checked_by_hand`
ставит человек после сверки документа, вопроса и эталона.

## demo

18 демо-вопросов организаторов и их база (`organizer/knowledge-base.zip`).
Элементы эталона составлены агентом по `organizer/demo_output.csv` и текстам
базы; `checked_by_hand: false` до сверки человеком. Решение настраивалось на
этих вопросах, поэтому результат здесь не является независимым измерением.
Проверки эталона — [test_elements.py](../validator_tests/test_elements.py):
все 18 ответов организаторов проходят, 21 искажение не проходит.

## legalbench-ru

139 задач открытой части [LegalBench-RU](https://huggingface.co/datasets/AlsKozlov/legalbench-ru)
(CC-BY-4.0, авторы — ru-legal contributors, v0.3): 115 «да/нет» и 24 с
развёрнутым ответом, у которых есть текст нормы. База — 265 норм: настоящие и
подставные неверные (`distractor_text`), имена файлов по заголовку нормы и хешу
текста, без признака подставной. Поле `context` решению не передаётся: в нём
подсказки к ответу. Закрытая часть набора не используется.

Эталон: «да/нет» — ответ открывается правильным словом, противоположное
запрещено; развёрнутый ответ — назван номер статьи эталонной нормы (смысл
ответа сохранён в `reference_answer` для ручной сверки). Все задачи авторы
пометили `needs_expert_review`: эталон сгенерирован и состязательно проверен,
но не размечен юристами. Сборка: `python3 -m evaluation.import_legalbench_ru <legalbench_ru.jsonl>`.
Большой корпус запускайте частями: `--shard 1/4` … `--shard 4/4`.
