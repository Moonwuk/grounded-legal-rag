# Юридический ассистент

Рабочий экран для русскоязычного юриста. Слева диалог, справа реестр и полный текст документа. Основная задача экрана — открыть основание и сверить исходную формулировку.

Палитра в web/static/style.css: тёмно-синий текст #182f36, фон #e9eeeb, белый лист #fffefa, акцент интерфейса #125e56 и жёлтый маркер #ffe397. Заголовки Georgia, интерфейс Segoe UI с системным запасным шрифтом. Поля и кнопки сохраняют размеры при ожидании. Цвет дополняет текст статуса. Панель документа немодальная, на узком экране располагается под чатом.

Метка в поле источника и подсветка на листе используют один мотив. Подсветка привязана к диапазону символов, выбранному ядром. Диалог хранится в памяти вкладки. При сбое сохраняется вопрос для повтора, ответ об ошибке в историю не добавляется.

Кнопка отправки и копирование выделенной цитаты используют контроллеры SL UI Library. Палитра подключена через локальные CSS-переменные. Служебные сообщения компонентов переведены на русский.
