# Юридический ассистент

Два связанных экрана работы. Слева диалог и поле вопроса, справа каталог и открытое положение. При первом ответе с источниками документ открывается без перемещения фокуса. Если пользователь уже открыл документ, он остаётся в панели. На узком экране каталог расположен после диалога.

Визуальная тема синей архивной папки. Основной акцент #164bc2, шапка #10275b, фон #eaf1fb, бумага #ffffff, подсветка положения #ffe398. Токены оформления находятся в web/static/appearance.css. По умолчанию используется системная тема, синий акцент и Arial 16 px. Настройки шрифта, темы и акцента применяются ко всему интерфейсу, включая просмотр документов и диалоги. Цвет жёлтой подсветки остаётся семантическим. Жёлтый маркер связывает кнопку источника и выделенный диапазон в тексте.

Карточка ожидания показывает архивариуса из приложенной пользователем сетки кадров. Локальный GIF зацикливает десять кадров поиска. Для системного режима уменьшенного движения используется первый неподвижный кадр. Статичный кадр с найденным листом появляется после ответа с источниками. Текст состояния различает ожидание, частичный ответ, уточнение, отказ и сбой.

Кнопка отправки и копирование цитаты используют контроллеры SL UI Library. Диалог хранится в памяти вкладки, при сбое вопрос можно повторить.
